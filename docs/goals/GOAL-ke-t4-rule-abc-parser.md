# GOAL-ke-t4-rule-abc-parser — 규칙 파서가 LLM 없이 어느 정도 맞추는가

## 골 한 줄

규칙 기반 ABC 파서를 보호자 실입력 128건에 돌려 안전 의뢰 재현율·주제 라우팅 정확도·LLM 폴백률을 실측해 무료 등급 LLM 예산 0 설계의 성립 여부를 판정 — verified by `node scripts/ke/ke-t4-rule-parser.mjs --gate` 종료코드 + `docs/ref/rnd/KE-T4-RESULT.json`, while preserving 앱 코드 0줄·양 레포 데이터 무변경.

## 0. 왜

4차 수렴(`PRODUCT-RESHAPE-CONVERGE-LOOP-2026-08-18.md`)의 불가역 크럭스:
**규칙 파서의 정확도 하나가 폴백률 → 무료 등급 단가 → 무료 비중 상한을 전부 결정한다.**
LLM 비용의 급소는 코칭(1회/일)이 아니라 **기록(N회/일)** 이고, 무료 비중까지 곱해지면 $30/월 예산이 즉시 터진다.

## 1. 코퍼스와 기준선 (실행 전 실측 · 봉인)

tailtree `data/ke1-v2-run.v0.json` — 지식iN·카페 실코퍼스 **128건**.

| 정답 축 | 커버리지 | 최빈 클래스 기준선 |
|---|---|---|
| `referral` (none 101 / trainer 16 / **vet 11**) | **128/128** | none 고정 = 78.9% |
| `curriculum` (15종, 배치당 8건 균등) | **128/128** | **12.5%** (reactivity 16건) |
| `entry_node` → 증상 | 58/128 (**55%가 null**) | 32.8% (fearful) |
| `consequence` = "서술 없음" | **63/128 (49%)** | — |

**설계 함의 2개 (실측)**
- `consequence` 를 **필수 입력으로 두면 안 된다** — 실제 보호자의 절반이 결과를 안 쓴다
- `entry_node` 는 55%가 비어 채점 축으로 부적합 → **보조 지표로만** 쓴다

## 2. Outcome

**PASS 조건 (셋 다)**

- **(a) 안전 — `vet` 재현율 100%** (11/11). 의학 신호를 놓치면 비뇨기·통증을 훈련으로 다루게 된다. `/감사` 규율: confident-wrong-unsafe 는 무조건 P0
- **(b) 안전 — 전체 의뢰(`vet`+`trainer`) 재현율 ≥ 70%** (27건 중 19건 이상)
- **(c) 주제 라우팅 정확도 ≥ 50%** — 실측 최빈 기준선 **12.5%** 의 4배, 무작위(1/15=6.7%)의 7.5배

**보고만 (임계 없음)**: LLM 폴백률 · 의뢰 정밀도(과잉 의뢰) · `entry_node` 보유 58건의 증상 일치율

**FAIL 시**: 무료 등급 LLM 예산 0 설계를 재검토한다. 폴백률 실측치로 무료 단가를 다시 계산하고, 감당 못 하면 무료 비중 상한을 낮춘다.

### 왜 놓쳤나 — 이게 실험의 값어치

놓친 vet 10건은 **키워드 몇 개를 더 넣으면 잡히는 종류가 아니다.**

| 유형 | 건수 | 예시 |
|---|---|---|
| **의학 도메인 명사** | 8 | 슬개골 탈구·관절염(2) · 멀미(3) · 치석(1) · 비만(1) · 중성화(1) |
| **사람 부상 사건** | 1 | *"개물림 피해자입니다"* — 개가 아니라 사람이 다친 건 |
| **맥락 추론 필요** | 1 | *"갑자기 낑낑거리고… 갑자기 제 손을 피하는데 무슨 일 생긴 걸까요"* — **증상 명사가 하나도 없다.** "갑자기 + 평소와 다름"이라는 추론이 필요하다 |

앞의 8은 **의학 용어 사전을 키우면 잡힌다**(유한·열거 가능). 그러나 마지막 1은 규칙으로 못 잡고, **안전 축은 재현율 100%가 요구되므로 "대부분 잡는다"로는 부족하다.**

과잉 의뢰 4건 중 2건은 부분 문자열 오탐 — `안 먹`이 *"양치를 …안 먹"* 문맥에 걸렸다.

### 살아남은 것 — 주제 라우팅

**0.477 은 실측 최빈 기준선 0.125 의 3.8배**다(무작위 1/15=0.067 의 7.1배). 임계 0.50 에 근소 미달했을 뿐, **규칙이 주제는 꽤 잡는다.** 이 축은 살릴 수 있다.

### 4분류 보고

- **재현됨**: 세 지표 전부. 입력이 정적 JSON, 난수 없음
- **근사됨**: 주제 라우팅 정답은 tailtree `curriculum` 15종이지 TaillogToss 축이 아니다. 실제 제품 라우팅과는 다를 수 있다
- **막힘**: 없음
- **불확실**: `entry_node` 가 55% 결측이라 증상 단위 정확도는 못 쟀다

### 결론 — "무료 등급 LLM 예산 0"은 성립하지 않는다. 단, 뒤집는 길이 있다

**LLM 을 없애는 게 아니라 옮긴다.**

- **안전 스크리닝만 LLM** — *"이 입력에 의학·안전 신호가 있나?"* 만 묻는 **수백 토큰 프롬프트**
- **주제 라우팅·ABC 구조화는 규칙** — 0.477 로 이미 기준선의 3.8배
- 비용은 **호출 수가 아니라 토큰 수의 함수**다. 현행 코칭 프롬프트가 **~8,100 토큰**이므로, 안전 스크리닝을 300 토큰으로 두면 **호출당 원가가 1/27**이 된다

즉 4차 수렴 Q3 #3(무료 LLM 예산 0)은 **Q3′(무료 LLM 은 안전 스크리닝 전용·초경량 프롬프트)** 로 개정해야 한다.

**후속 측정 후보**(이번 실험 범위 밖): 의학 용어 사전을 확장하면 vet 재현율이 어디까지 오르나. 단 §4 제약상 **이번 사전은 튜닝하지 않았다** — 확장은 별도 실험으로.
