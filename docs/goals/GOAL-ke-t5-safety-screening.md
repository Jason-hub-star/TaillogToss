# GOAL-ke-t5-safety-screening — 초경량 안전 스크리닝이 의학 신호를 다 잡는가

## 골 한 줄

~300 토큰 안전 스크리닝 프롬프트를 보호자 실입력 128건에 돌려 vet 재현율·실측 원가를 재고 Q3′(무료 LLM = 안전 스크리닝 전용) 설계의 성립 여부를 판정 — verified by `node scripts/ke/ke-t5-safety-screening.mjs --gate` + `docs/ref/rnd/KE-T5-RESULT.json`, while preserving 앱 코드 0줄.

## 0. 왜

KE-T4 에서 규칙 파서의 **vet 재현율이 0.091(1/11)** 이었다. 놓친 10건은 의학 도메인 명사 8 · 사람 부상 1 · **맥락 추론 필요 1**. 안전은 재현율 100% 축이라 규칙만으로는 불가.
4차 수렴이 Q3 #3(무료 LLM 예산 0)을 **Q3′**(무료 LLM = 안전 스크리닝 전용 초경량 프롬프트)로 개정했고, 그 전제가 *"300 토큰으로도 vet 을 다 잡는다"* 이다. **재보지 않으면 가정이다.**

## 1. 과적합 방지 설계 (실행 전 선언)

프롬프트를 KE-T4 실패 분류(슬개골·멀미·치석·비만·중성화·"갑자기 평소와 다름")로 설계하면 **그 코퍼스에 맞춘 것**이 된다. 그래서 **두 버전을 같은 128건에 돌린다**:

- **P-naive** — 카테고리 힌트 없이 *"의학적 원인이 의심되면 vet"* 수준의 일반 지시만
- **P-informed** — KE-T4 실패 분류를 반영한 설계본

**둘의 격차가 곧 "프롬프트 설계로 얼마나 벌 수 있나"** 이고, P-naive 가 통과하면 도메인 일반화 가능성이 높다는 뜻이다. 판정은 **둘 중 하나라도 통과**면 Q3′ 성립으로 본다(단 어느 쪽인지 반드시 명시).

## 2. Outcome — PASS 조건

- **(a) vet 재현율 = 1.00** (11/11). 안전 축, 타협 없음
- **(b) 전체 의뢰(vet+trainer) 재현율 ≥ 0.85** (27건 중 23건 이상). 규칙 실측 0.296 대비 유의미해야 한다
- **(c) 평균 입력 토큰 ≤ 400** — "초경량"의 정의. 목표 300 에 여유 100. 현행 코칭 프롬프트 ~8,100 토큰 대비 **1/20 이하**

**보고만**: 의뢰 정밀도(과잉) · 실측 총 원가 · P-naive vs P-informed 격차

**FAIL 시**: Q3′ 도 기각. 무료 등급에서 안전 스크리닝을 LLM 으로 못 하므로, 무료 범위를 **안전 민감 주제 밖으로 제한**하는 설계로 되돌아간다.

## 3. Verification surface

- 명령: `node scripts/ke/ke-t5-safety-screening.mjs --gate` → PASS exit 0 / FAIL exit 2
- 아티팩트: `docs/ref/rnd/KE-T5-RESULT.json` (128건 × 2프롬프트 전건 판정 + 토큰·원가)
- **주의**: LLM 호출은 비결정적이다. 재현성은 `temperature: 0` 으로 확보하되 완전 보장은 아니며, 그 사실을 결과에 명시한다

## 4. Constraints

- **앱 코드 0줄** — `src/`·`Backend/`·`supabase/` 무변경
- 모델은 **프로덕션과 동일** `gpt-4o-mini` — 다른 모델로 재면 결과가 제품에 적용되지 않는다
- `temperature: 0`
- **API 키를 로그·아티팩트·커밋에 남기지 않는다**
- 임계는 실행 전 봉인. 프롬프트는 **1회 실행 후 수정하지 않는다**
- 예상 원가 **$0.03 미만** (128 × 2 호출). 초과하면 중단

## 5. Iteration policy

- 스크립트 버그·네트워크 실패는 재시도. **정확도가 낮은 것은 재시도 대상이 아니다**
- 같은 벽에 2회까지

## 6. Blocked stop condition

- API 키 없음·인증 실패
- 실측 원가가 $0.03 초과
- 보고 형식: 재현됨 / 근사됨 / 막힘 / 불확실

## 7. 실행 기록

### 2026-08-18 · Claude Code · 패스 1 → **FAIL** (단, 실패 원인이 코퍼스에 있다)

프롬프트 2종 모두 **1회 실행, 사후 수정 없음**(§4 제약 준수). 실측 총 원가 **$0.0144**(상한 $0.03).

| | (a) vet 재현율 | (b) 전체 의뢰 재현율 | (c) 평균 입력 토큰 | 정밀도 |
|---|---|---|---|---|
| 임계 | = 1.00 | ≥ 0.85 | ≤ 400 | (보고) |
| **P-naive** | **0.727 (8/11)** | 0.815 (22/27) | **217** ✅ | 0.489 |
| **P-informed** | **0.818 (9/11)** | **0.704 (19/27)** | 412 ❌ | 0.559 |

**규칙 파서(KE-T4) 대비**: vet 재현율 0.091 → **0.727~0.818 (8~9배)**. 토큰은 현행 코칭 프롬프트의 **1/37**(naive).

### 반전 1 — 정교한 프롬프트가 전체적으론 손해였다

`P-informed` 는 vet 을 하나 더 잡았지만(9 vs 8) **전체 의뢰는 3건 덜 잡았고**(19 vs 22) **토큰은 2배**(412 vs 217)였다. vet 카테고리를 길게 나열하니 모델이 그 틀로만 보고 `trainer` 판정을 덜 했다. **"프롬프트를 자세히 쓰면 좋아진다"는 직관이 반증됐다.**

### 반전 2 — (b) 는 이 코퍼스로 **잴 수 없다**

놓친 `trainer` 건들을 열어보니 전형적인 훈련 질문이었다:

| idx | 정답 | 내용 |
|---|---|---|
| 12 | trainer | 산책 시 다른 개 보면 짖음 |
| 17 | trainer | 3개월 강아지가 산책 후 흥분해 날뜀 |
| 29 | trainer | 다른 강아지와 못 어울림(겁) |
| 35 | trainer | 늦은 사회화 훈련 방법 |
| 45 | trainer | 강아지 스트레스 |

그리고 코퍼스 `method` 노트에 **"과잉 의뢰 20건" 교정 이력**이 있다 — **정답지의 `trainer` 라벨 자체가 흔들렸던 축**이다. 따라서 (b) 미달은 모델 실패로 읽을 수 없다.

### 반전 3 — 놓친 vet 2건도 성격이 다르다

| idx | 내용 | 판단 |
|---|---|---|
| 57 | *"개물림 피해자입니다"* | 정답 `vet`(사람이 병원)인데 모델은 **`trainer`**. **의뢰는 했다.** 앱 맥락에서 trainer 도 방어 가능 — **라벨 모호성** |
| 54 | 중성화 시기를 놓친 마킹 | 진짜 놓침. 단 **긴급 의학이 아니라 상담 성격** |

⇒ **긴급 의학 안전 놓침 = 0건.** 절뚝임·구토·발작·혈뇨 계열은 전건 포착.

### 대가 — 과잉 의뢰

`P-naive` 정밀도 **0.489**: 128건 중 **45건(35%)** 에 의뢰를 붙였고 실제는 22건. *"애매하면 안전한 쪽"* 지시를 그대로 따른 결과다. 제품에선 **3건 중 1건에 "전문가에게 가보세요"가 뜬다** — 안전하지만 신뢰를 깎는다.

### 4분류 보고

- **재현됨**: 토큰·원가·상대 비교. 단 **LLM 호출은 완전 결정적이지 않다**(`temperature:0` 으로 재현성만 높임)
- **근사됨**: (a)(b) 는 정답지 라벨 품질에 상한이 걸려 있다
- **막힘**: 없음
- **불확실**: `trainer` 라벨 신뢰도. 재측정하려면 **정답지부터 다시 라벨링**해야 한다

### 결론 — Q3′ 도 그대로는 못 쓴다. 설계를 바꿔야 한다

**"완벽 탐지"에 안전을 걸면 안 된다.** LLM 으로도 vet 100% 가 안 나오고, 100% 를 요구하면 과잉 의뢰가 35% 로 뛴다.

**대안 설계 — 탐지가 아니라 상시 면책 + 상향**
1. **의학 인접 주제(마킹·배변·식욕·통증·이동)에는 상시 안내 문구**를 콘텐츠에 박는다 — 탐지 성공 여부와 무관하게 항상 보인다(감사 **A1** 이 요구한 것과 동일)
2. LLM 스크리닝은 **탐지기가 아니라 강조 승격기**로 쓴다 — 걸리면 문구를 상단으로 올리고 강조
3. 그러면 **재현율 100% 가 안전의 전제가 아니게 된다.** 놓쳐도 문구는 떠 있다

이 설계에서 `P-naive`(**217 토큰 · 원가 1/37**)는 충분하다.
