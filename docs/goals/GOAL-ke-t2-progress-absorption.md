# GOAL-ke-t2-progress-absorption — 커리큘럼 진행률을 그래프 좌표로 잃지 않고 옮길 수 있는가

## 골 한 줄

커리큘럼 109스텝을 how 좌표로 흡수 매핑했을 때 실패 0 · 진행률 변화폭 ±10%p 이내인지 실측해 축 통일(P7 #4) 착수 여부를 판정 — verified by `node scripts/ke/ke-t2-progress-absorption.mjs --gate` 종료코드 + `docs/ref/rnd/KE-T2-RESULT.json`, while preserving 앱 코드 0줄·양 레포 데이터 무변경.

## 0. 왜

2차 수렴(수렴 SSOT §10)이 "스키마 무변경"을 철회하고 **축 통일(흡수)** 를 택하면서 새 크럭스가 생겼다:
스텝 **109** ↔ how **1,035스텝**(207원자 × 5). 1:1 이 아니라 매핑이 어긋나면 **기존 사용자의 진행률이 튄다** — "3일차까지 했는데 다시 1일차"는 이탈 사유다.

## 1. Outcome

커리큘럼 7종 × 109스텝 전부에 대해 대응 how 좌표를 산출하고 이진 판정한다.

### 패스 0 정정 (실행 전 · 결과 미관측)

두 가지를 실행 **전에** 확정한다. 임계를 낮추는 게 아니라 **미정의였던 것을 정의**한다.

**정정 1 — 스텝 수는 109가 아니라 108이다.**
`catalog.json`·published `manifest.json`·기존 문서가 전부 109라 적었으나, 실측 `step()` 호출은 **108**이다. 109는 `function step(` **정의 자체가 카운트에 섞인 off-by-one**이다 (`s.count("step(")` = 109, 정의 제외 = 108).

**정정 2 — "매핑"의 정의.**
비율 매핑(k/N → 같은 비율)은 정의상 편차 0이라 시험이 성립하지 않는다. 실제 위험은 비율이 아니라 **내용이 엉뚱한 곳에 떨어지는 것**이다("차 키 소리 둔감화"를 하던 사람이 "매트에서 쉬기"로 착지). 따라서:

- 신 좌표 = goal 사다리의 원자 순서 × 원자별 how `steps[]` 를 이어붙인 시퀀스
- 매핑 = 구 스텝 지시문 ↔ 신 스텝 본문의 **한글 문자 bigram Jaccard 최대** 지점

**PASS 조건 (둘 다)**
- **(a) 매핑 실패 0** — 108스텝 중 최고 유사도가 **0.10 미만**인 것이 없다 (0.10 = 한글 bigram 기준 사실상 무관)
- **(b) 진행률 변화폭 ±10%p 이내** — 구 위치 비율(order/커리큘럼 총스텝)과 신 위치 비율(매핑 인덱스/신 총길이)의 **최대 절대편차**

**FAIL 시**: 흡수안 철회 → 2차 수렴 R2 의 기각안(두 축 공존)으로 되돌아가 분기 비용을 감수한다.

### 지표 한계 — (a)는 신뢰하지 말 것

매핑을 눈으로 대조하니 **주제적으로는 정확했다**:

| 구 스텝 | 매핑된 신 좌표 | 판단 |
|---|---|---|
| "평소 외출할 때 입는 옷을 완벽하게 갖춰 입으세요" | `skill.emotional.sep_cue_desens` step0 (외출 신호 둔감화) | **정확** |
| "신발을 신고 도어락 소리를 낸 뒤 나가지 않고 돌아오세요" | `sep_cue_desens` step1 | **정확** |
| "문을 열고 나간 뒤 딱 3초만 세고 다시 들어오세요" | `sep_cue_desens` step4 | **정확** |
| "차 키를 짤랑거리거나 가방 지퍼를 여닫는 소리를 5분간" | `skill.self_regulation.sep_graduated` step1 | 관련 |

유사도 0.04~0.10 은 **한글 문자 bigram 이 서로 다른 표현을 못 잡는 지표 한계**지 오매핑이 아니다.
따라서 **(a) 99건 실패는 대부분 거짓양성**이고, **구속력 있는 실패는 (b) 편차 99.1%p** 하나다.

### 진짜 이유 — 두 시스템의 교육 철학이 다르다

| | 구 커리큘럼 | 신 사다리 |
|---|---|---|
| 진입 | **문제 행동부터 바로** (Day1 = 외출 신호 둔감화) | **기초부터** (마커·보상·주의·매트… 약 90스텝 뒤에 분리불안 도착) |
| 스텝 수 | 15~18 | 79~142 (**5.3~9.5배**) |
| `sep_cue_desens` 위치 | 0.07 (첫 스텝) | **0.86** |

그래서 진행률을 그대로 옮기면 **7% → 86%** 로 튄다. 반대로 앞 기초를 미완으로 두면 "3일차까지 했는데 처음부터"가 된다. **어느 쪽도 진실이 아니다** — 좌표 문제가 아니라 **커리큘럼 설계 철학의 비호환**이다.

### 4분류 보고

- **재현됨**: (b) 편차. 입력이 정적이라 결정적
- **근사됨**: (a) 매핑 실패 — bigram Jaccard 는 한국어 의미 유사도의 약한 근사다. 눈 대조로 주제 정확성 확인
- **막힘**: 없음
- **불확실**: 실제 사용자 진행 분포를 모른다(균등 가정). 대부분이 Day1~2 에 몰려 있다면 손실이 작을 수 있다
