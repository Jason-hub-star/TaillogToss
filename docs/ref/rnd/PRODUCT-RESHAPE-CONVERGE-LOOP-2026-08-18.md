→ **Q1**: ABC 구조화 = **규칙 우선 · LLM 폴백**.

**적대적 반박** — *"무료 등급의 LLM 예산을 0 으로 두면 되지 않나?"*:
**채택.** 무료 = 규칙 파서 + 칩 + `rule_engine` 폴백만. LLM 은 **코칭 1회/일**에만 쓴다(현행 유지). 무료 확대가 **단가가 아니라 콘텐츠 접근권**으로 이뤄지면 비용이 사용자 수에 선형 비례하지 않는다.
그리고 3차 P11 의 **번들 적재(409KB)** 가 이걸 가능하게 한다 — 콘텐츠가 앱에 있으니 서버·LLM 없이 열어줄 수 있다.

→ **Q2**: 무료 확대의 통화는 **LLM 호출이 아니라 콘텐츠 접근권**.
