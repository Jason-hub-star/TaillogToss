```ts
{ title: "'이름 부르기' 숨바꼭질 게임", description: "이름을 부르는 대신, 강아지 시야 밖에서 손으로 벽을 살짝 긁거나 혀를 차는 소리를 내보세요. '어디서 났지?' 하고 스스로 탐색해서 보호자를 찾아오면 즉시 터그놀이 5초로 보상합니다. 이름 반응을 훈련이 아닌 탐험 게임으로 경험하게 합니다." }
```

**초안 altC (Adaptive)**
```ts
{ title: "시각 신호로 대체 (노견·청각 약화)", description: "청각이 약해진 노견은 이름 호출 대신 손을 가볍게 흔들거나 리드줄을 살짝 당기는 촉각 신호를 사용하세요. 트라우마 있는 강아지는 높은 톤이 오히려 자극이 될 수 있으니 낮고 부드러운 속삭임으로 시작하고, 반응이 오면 즉시 조용한 칭찬과 간식을 줍니다." }
```


**초안 altC (Adaptive)**

**초안 altB (PlayBased)**

**초안 altC (Adaptive)**

## 2. separation_anxiety — altC 누락 (7스텝)

**altB**: 외출 소품 '일상화' 놀이 (있음)  
**초안 altC (Adaptive)**
```ts
{ title: "둔감화 속도를 강아지 반응도에 맞게 조절", description: "외출복 착용 자체에서 이미 패닉 반응(떨기, 과호흡)을 보인다면 코트 전체가 아닌 양말 하나만 신고 앉아있는 것부터 시작하세요. 구조견이나 트라우마가 있는 강아지는 1주일 이상 양말만으로 반복해도 충분합니다. 아파트라면 TV 소리가 더 큰 자극이 될 수 있으니 무음으로 진행하세요." }

```

## 3. reactivity_management — altC 누락 (5스텝)

**altB**: '안전 구역'을 탐험 기지로 만들기 (있음)  
**초안 altC (Adaptive)**
```ts
{ title: "소음 종류와 강도를 강아지 민감도에 맞게 설정", description: "청각이 예민한 강아지는 백색소음도 처음엔 불안 자극이 될 수 있습니다. 자연 소리(새, 물소리)를 매우 낮은 볼륨(20% 이하)으로 시작해 3~4일 후 볼륨을 높이세요. 노견은 청각이 약해 이미 자연스러운 둔감화 상태일 수 있으니 이 단계를 짧게 진행하거나 건너뛰어도 됩니다. 아파트 위층 소음이 주된 자극이라면 그 소리와 유사한 쿵쿵 소리를 녹음해 재생하는 것이 더 효과적입니다." }
```
